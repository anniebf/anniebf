## Sobre Minha Atuação

Atuo profissionalmente nesta organização como **Desenvolvedor de Software e Automação**, aplicando conceitos avançados de Engenharia de Software no desenvolvimento de soluções corporativas de alta eficiência.

Meu foco principal está na arquitetura de sistemas robustos, inteligência de processos e automações de ponta a ponta:

* **Automação de Processos & RPA:** Desenvolvimento de soluções robustas em *Python* e *Selenium* para otimização de fluxos corporativos, auditoria e processamento de dados privados e governamentais.
* **Integração e Visão Computacional:** Implementação de fluxos inteligentes unindo inteligência de negócios, machine learning e tratamento automatizado de dados.
* **Backend & Infraestrutura:** Criação de APIs e microsserviços integrados, utilizando contêineres *Docker* e ambientes *Linux* para garantir entregas escaláveis e seguras.
